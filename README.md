# Dungeon Composer

Seeded dungeon generator built with React + TypeScript + Vite.

## Features (MVP)
- Seed-based deterministic generation (`Math.random()` is not used for generation).
- Top-down tilemap preview rendered on `<canvas>` (128x96 grid, 16px tiles).
- Rectangular room carving + corridor generation from graph topology.
- Start/Boss marker rendering on the tilemap.
- PNG export with scale (`1x/2x/4x`) and background mode (`white/transparent`).
- Core unit tests for RNG, generation, layout, and tilemap validation.

## Local development
```bash
npm install
npm run dev
```

## Build and preview
```bash
npm run build
npm run preview
```

## Test
```bash
npm run test:run
```

## Deployment
- GitHub Actions workflow: `.github/workflows/deploy.yml`
- Trigger: push to `main`
- Output: `dist/` deployed to `gh-pages` branch.

If your Pages URL is `https://<user>.github.io/DungeonGen/`, keep:
- `VITE_BASE_PATH=/DungeonGen/` (default in `vite.config.ts`)

For a custom domain root deployment:
- set `VITE_BASE_PATH=/`

## Asset note
- Tile and marker assets in `src/assets/tiles` were generated for this project workflow (`Generated by Codex`).
- External image URLs are avoided to prevent canvas CORS/taint issues during PNG export.
